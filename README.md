# Repositório Central Oxetech Academy - Automação e Integração de Sistemas
- Exploração de técnicas e ferramentas de automação e integração de sistemas utilizando APIs, RPA e plataformas no-code. 
- Ênfase em produtividade, interoperabilidade e inovação tecnológica

## Objetivo Geral
- Capacitar o aluno a criar soluções de automação e integração entre sistemas, utilizando ferramentas modernas e acessíveis.

## Objetivos Específicos
- Integrar sistemas via APIs REST e Webhooks. 
- Desenvolver automações com RPA.
- Utilizar plataformas no-code para prototipagem rápida. 
- Compreender fluxos de dados e interoperabilidade. 
- Avaliar eficiência e ROI de processos automatizados.

## Pré-requisitos
- Noções de lógica de programação e fundamentos de sistemas web.

## Metodologia 
- Aulas teóricas e práticas com estudos de caso em plataformas como Zapier, n8n e UiPath.

## Avaliação 
- Participação e frequência: 20% 
- Práticas: 30% 
- Projeto Final Integrador: 50%
- Critério de aprovação: média >= 7 e frequência mínima de 75%

## Recursos Didáticos
- [Zapier](https://zapier.com)
- [n8n](https://n8n.io)
- [UiPath](https://www.uipath.com)
- [Postman](https://postman.com)
- AVA OxeTech

## Projeto Final Integrador
- Automação completa de um processo corporativo com integração de sistemas e apresentação funcional.
